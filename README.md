# WRC — პაციენტის მომსახურების ინდექსი (PSI)

Next.js + PostgreSQL აპლიკაცია დასავლეთის რეგიონალური ცენტრისთვის.

## რა შედის

- ლოგინი და როლები
- პაციენტების სია (მარცხნივ) + ძებნა
- Excel იმპორტი (`ისტორიები გახსნით` ფორმატი)
- ღილაკი **პაციენტების განახლება** (HIS API)
- ხელით ახალი პაციენტი
- კითხვარის კონსტრუქტორი (დამატება/წაშლა, ვარიანტები, რეიტინგი)
- გამოკითხვა + რედაქტირება
- შედეგები აპში (სახელებით)
- იმეილი დირექტორებს — **სახელების გარეშე**, მხოლოდ რაოდენობა და კარგია/საყურადღებოა/გამოსასწორებელია

## სწრაფი გაშვება (ლოკალურად)

### 1. PostgreSQL

```bash
docker compose up -d
```

ან გამოიყენეთ თქვენი Postgres და განაახლეთ `DATABASE_URL` `.env` ფაილში.

### 2. დამოკიდებულებები და ბაზა

```bash
npm install
npx prisma migrate dev --name init
npm run db:seed
```

### 3. აპი

```bash
npm run dev
```

გახსენით http://localhost:3000

## გარემოს ცვლადები (`.env`)

იხილეთ `.env` მაგალითი. მნიშვნელოვანი:

- `DATABASE_URL` — Postgres
- `AUTH_SECRET` — შემთხვევითი სტრიქონი
- `EMAIL_TO_*` — ახლა ყველა `z.jurkhadze@gmail.com`
- `SMTP_*` — იმეილის გასაგზავნად (ცარიელი SMTP = იმეილი გამოტოვდება, ლოგი ინახება)
- `HIS_API_URL` / `HIS_API_KEY` — პაციენტების API სინქი

## შიდა სერვერზე

1. დააკოპირეთ პროექტი VM-ზე
2. დააყენეთ Node.js + PostgreSQL
3. `.env` მოარგეთ
4. `npm install && npx prisma migrate deploy && npm run db:seed`
5. `npm run build && npm start` (ან PM2 + Nginx)

## შეფასების ლოგიკა

- **კარგია** — კარგი პასუხების წილი **≥ 70%**
- **საყურადღებოა** — **50–69%**
- **გამოსასწორებელია** — **&lt; 50%** (30–50%-ის ზონაც აქ ემატება)

(N/A — მიზეზი `0` — შეფასებაში არ მონაწილეობს.)

ნეგატიური = ვარიანტი მონიშნულია როგორც „ნეგატიური“, ან რეიტინგი ≤ 2.
